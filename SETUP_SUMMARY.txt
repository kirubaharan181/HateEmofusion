PROJECT ANALYSIS:
═════════════════════════════════════════════════════════════════════════════

NAME: HateFusion
DESCRIPTION: Advanced Hate Speech Detection with Emoji-Aware Feature Extraction

KEY FEATURES:
• Multi-model support (BERT + DistilBERT)
• Dual classification schemes (3-way & 7-way)
• 3-layer emoji detection (294 + 969 + 5225 emojis)
• Multi-dataset training (Toxigen, IHC, Gab)
• Explainability (LIME, SHAP, BertViz)
• Multiple interfaces (Jupyter, Gradio, Flask, Python)

MODELS:
• ihc_3way_bert - 3-way classification with BERT
• ihc_3way_distilbert - 3-way with faster DistilBERT
• ihc_7way_bert - 7-way fine-grained classification
• ihc_7way_distilbert - 7-way with DistilBERT

DATASETS:
• Toxigen (165 MB) - Large toxicity dataset
• Implicit Hate Corpus (5 MB) - Multi-stage annotations
• Gab Hate Corpus (4.5 MB) - Real platform data
• Emoji datasets (131 KB) - 1263 emojis total

TECHNOLOGIES:
✓ PyTorch 2.0+ - Deep learning framework
✓ Transformers 4.35+ - BERT/DistilBERT models
✓ sklearn - ML utilities
✓ LIME & SHAP - Model explanability
✓ BertViz - Attention visualization
✓ Gradio - Interactive interface
✓ Flask - REST API
