⚠️  TROUBLESHOOTING:

If STEP 3 fails, check:

Issue: "Repository not found"
→ Solution: Make sure you created the empty repository first in STEP 1
→ Check: https://github.com/kirubaharan181/HateEmofusion exists

Issue: "Authentication failed" or "403 Forbidden"
→ Solution: Check your token is correct (copy it exactly from GitHub)
→ Action: Generate a new token if you're unsure

Issue: "fatal: the remote end hung up unexpectedly"
→ Solution: Try again, might be temporary network issue
→ Command: git push -u origin main (try once more)

Issue: "Updates were rejected because the tip of your current branch is behind"
→ Solution: Run these commands:
→ git pull origin main --allow-unrelated-histories
→ git push -u origin main

Issue: Command not found or "git" not recognized
→ Solution: Install Git from https://git-scm.com/download/win
→ Then restart Command Prompt and try again
